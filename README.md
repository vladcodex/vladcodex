**Swept** — open-source cleaner, app installer and tweaker for Windows 10/11 in one window.

22 cleanup categories, 24 programs fetched from the vendors' own CDNs and verified by signature or pinned hash, 12 tweaks with a system restore point created first. Portable, MIT, no telemetry, no background services.
